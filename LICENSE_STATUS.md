# Author-code license selection

The author's code has not been assigned a new open-source license by this preparation. Upstream files retain their existing licenses in LICENSES. Public visibility alone does not grant an open-source reuse license for the author's work.

Recommended choice: MIT for the author's original build/validation/integration scripts, subject to the author's choice and any applicable institutional ownership obligations. A top-level license must clearly exclude third-party files, which retain their own terms. The manuscript and illustrations can be licensed separately.

Before announcing an open-source release, select and add the actual license, update CITATION.cff if appropriate, and regenerate the manifest. No license choice is needed to inspect the prepared files locally.
